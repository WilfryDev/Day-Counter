Parámetros del Endpoint

    

      
        

          Parámetro
          Tipo
          Requerido
          Descripción
        

      
      
        

          start
          YYYY-MM-DD
          Sí
          Fecha desde la que inicia el cálculo.
        

        

          end
          YYYY-MM-DD
          No
          Fecha final (por defecto hoy).
        

        

          include
          boolean
          No
          true para incluir el primer día como día 1.
        

        

          business
          boolean
          No
          true para computar solo días hábiles (lunes a viernes).
        

        

          format
          string
          No
          format=json devuelve el payload JSON puro.
